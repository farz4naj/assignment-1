# 🇦🇫 Safar Afghanistan

### Discover the Beauty, History, and Culture of Afghanistan

## 📖 About the Project

Safar Afghanistan is a responsive website created to showcase the natural beauty, historical landmarks, and cultural heritage of Afghanistan.

The website provides visitors with an educational virtual journey through some of Afghanistan's most remarkable places.

## ✨ Features

- **Destination Cards:** Explore different places across Afghanistan.
- **Category Filters:** Filter destinations by Nature, Heritage, and Cities.
- **Destination Details:** View additional information about each location.
- **Dark and Light Mode:** Switch between two visual themes.
- **Responsive Design:** Designed to work on desktop, tablet, and mobile screens.
- **Mobile Navigation:** Easy-to-use navigation menu for smaller screens.
- **Contact Form:** Allows visitors to submit messages using EmailJS (after configuration).

## 🏛️ Featured Destinations

- Band-e Amir — Bamiyan Province
- Bamiyan Valley — Bamiyan Province
- Blue Mosque — Mazar-i-Sharif
- Friday Mosque — Herat
- Darul Aman Palace — Kabul
- Minaret of Jam — Ghor Province

## 🚀 How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Use the Live Server extension to preview the website in your browser.

An internet connection is required for externally hosted images, fonts, and EmailJS.


**Note:** The contact form will not send emails until EmailJS has been configured correctly.

## 🎯 Project Goal

The goal of Safar Afghanistan is to celebrate Afghanistan's identity by presenting its landscapes, architecture, history, and cultural heritage through a simple and attractive digital experience.
